# 📚 ExamVault

### Learn • Practice • Succeed

ExamVault is a Previous Year Question Paper Finder website designed to help students easily find and practice previous year examination papers.

## ✨ Features

- Search question papers
- Filter by university
- Filter by semester
- Filter by examination year
- View and download PDFs
- Admin panel
- Upload and manage question papers
- Important questions section

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Browser LocalStorage

## 📂 Project Structure

├── index.html

## 🚀 How to Use

1. Open the ExamVault website.
2. Select your university.
3. Choose your semester.
4. Select the examination year.
5. Search for your subject.
6. View available question papers.
